How to print
  1. Drop the STL in your slicer.
  2. Check the print height is 71.9 mm. The stand width becomes the height in vase mode.
  3. Turn on vase mode. In PrusaSlicer: Print Settings → Layers and perimeters → Spiral vase.
  4. Set the extrusion width to 0.6 mm. Lips and floors are drawn 1.2 mm thick so the path going out and back fuses into one solid wall.
  5. Removing the bottom layers leaves the hollow look.
